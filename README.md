Repo ini hanya berisi **rilis APK resmi** dan info pembaruan Tokoni untuk Android.
Tokoni **sepenuhnya gratis**: tanpa langganan, tanpa iklan, dan tanpa pembelian di dalam aplikasi.

## Cara memasang

1. Unduh **[Tokoni.apk](https://github.com/dhimasbagus402/Tokoni-Android/releases/latest/download/Tokoni.apk)** dari rilis terbaru.
2. Buka file itu di HP. Bila diminta, izinkan browser / pengelola file **memasang aplikasi tidak dikenal**.
3. Ketuk **Instal**, lalu buka Tokoni.

Sudah memakai versi web? Hubungkan Google Drive di aplikasi Android dengan akun Google yang sama, data ikut tersinkron.

## Pembaruan

Tokoni memeriksa pembaruan sendiri sekali sehari (dan lewat **Lainnya → Pengaturan → Versi aplikasi**).
Bila ada versi baru, Tokoni menawarkan **Perbarui sekarang**:

- APK diunduh dari halaman [Releases](https://github.com/dhimasbagus402/Tokoni-Android/releases) repo ini.
- File dicek SHA-256-nya sebelum dipasang, dan Android hanya mau memasang APK yang ditandatangani kunci yang sama.
- Pembaruan dipasang menimpa aplikasi lama, jadi **data di HP tetap ada**.

Info versi terbaru ada di [`TOKONI_UPDATE.json`](TOKONI_UPDATE.json).

> Pasang Tokoni hanya dari repo ini atau dari [tokoni.my.id](https://tokoni.my.id/). APK dari sumber lain tidak resmi.

## Memeriksa keaslian APK (opsional)

SHA-256 tiap rilis tertulis di catatan rilisnya dan di `TOKONI_UPDATE.json`. Di PC:

```powershell
Get-FileHash .\Tokoni.apk -Algorithm SHA256
```

### English

Tokoni is a **completely free** point-of-sale and bookkeeping app for small shops (Android & web).
This repository only hosts the **official APK releases** and the update info.
Download the [latest Tokoni.apk](https://github.com/dhimasbagus402/Tokoni-Android/releases/latest/download/Tokoni.apk),
open it on your phone and allow installing unknown apps if asked. The app checks this repository for updates once a day,
verifies the SHA-256 of the download, and installs it over the existing app so your data stays on the phone.
